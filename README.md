# Sonorum — RF03 / Migração para Supabase Auth

Instruções completas e queries: **[README_SUPABASE.md](README_SUPABASE.md)**.

- Pasta `querys_supa/`: SQL numerado para instalar no SQL Editor.
- `frontend/.env` e `backend/.env`: espaços reservados para URL/chaves; nunca inserir Secret key no navegador.

- Sem conta administrativa padrão: cadastrar a própria conta e executar `04_promover_admin_MANUAL.sql`.
